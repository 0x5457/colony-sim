# colony-sim

类 [RimWorld](https://rimworldgame.com/) 的 2D 殖民地模拟游戏。在程序生成的荒野中建立定居点，管理殖民者，发展科技，抵御威胁。

> **状态**：早期开发中（测试 DeepSeek V4 Flash 模型的表现）

---

## 快速开始

```bash
# 安装依赖
npm i

# 启动开发服务器（热重载）
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

浏览器打开 `http://localhost:5173`（Vite 默认端口）。

## 玩法简介

| 模块 | 说明 |
|------|------|
| 🏗️ **建造** | 放置蓝图 → 殖民者自动施工 → 建成可用 |
| 🌾 **农业** | 农田种植作物，成熟后收割 |
| 🔥 **资源** | 砍树（木材）、挖矿（钢铁）、采集（植物纤维） |
| 🍳 **烹饪** | 将生食加工为熟食，殖民者自动取用 |
| 🛏️ **休息** | 床铺提供睡眠，篝火/火炉提供照明与温暖 |
| 🤖 **AI 任务板** | 殖民者按优先级自动接受并执行工作 |
| ⚔️ **威胁** | 遭遇事件与战斗系统 |
| 💾 **存档** | 支持保存/加载，共享种子可复现世界 |

**操作**：
- **左键拖拽** 或 **WASD / 方向键** — 平移视角
- **鼠标滚轮** — 缩放
- **左键点击** 殖民者 — 选中 / 取消选中
- **右键点击** 地面（选中殖民者时）— 下达工作指令
- **建造模式** — 左键点击放置蓝图
